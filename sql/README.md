# SQL Scripts

This directory contains all SQL scripts used in the FoodFlow Backend project.

## Script Execution Order

1. `01_create_database.sql`
    - Creates the FoodFlow database.

2. `02_create_tables.sql`
    - Creates all database tables and relationships.

3. `03_insert_sample_data.sql`
    - Inserts sample data for testing.

4. `04_test_queries.sql`
    - Contains SQL queries used to verify the database.

Always execute the scripts in the above order.
